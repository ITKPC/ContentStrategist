# KPC Content Strategist

Helping KPC communicate with confidence.

## Sprint 1 foundation

This repository contains the initial application shell for KPC Content Strategist.

### Included

- React and TypeScript application scaffold
- Vite build configuration
- Responsive KPC-branded interface
- Six-step communications workflow
- Source text entry with live word count
- Netlify deployment configuration
- GitHub Actions build verification
- ESLint and TypeScript configuration

### Workflow

1. Source
2. Analysis
3. Plan
4. Create
5. Before You Publish
6. Communications Package

### Local development

```bash
npm install
npm run dev
```

### Production build

```bash
npm run build
```

The production output is written to `dist/`.
